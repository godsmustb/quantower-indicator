# Development Roadmap

## Current Version: Phase 1 (v1.0)

Phase 1 focuses on core functionality compatible with Quantower FREE license.

### Completed Features

- [x] Market Regime Detection (Choppiness Index + ADX)
- [x] Previous Day Levels (PDH/PDL/PDC)
- [x] Session Kill Zone Tracking (Asia, London, NY AM, NY PM)
- [x] Opening Range (9:30-10:00 AM ET)
- [x] Swing Liquidity Levels (BSL/SSL)
- [x] Volume Spike Detection
- [x] Confluence Scoring System (0-5 points)
- [x] Alert System
- [x] Configurable Parameters
- [x] Information Panels

## Contributing

We welcome contributions! Here's how you can help:

### Bug Reports

1. Check existing issues on GitHub
2. Create a detailed bug report with:
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable
   - Quantower/Windows version

### Feature Requests

1. Check the roadmap above first
2. Open a GitHub issue with:
   - Clear description of the feature
   - Use case explanation
   - Any technical suggestions

### Code Contributions

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request with:
   - Description of changes
   - Testing performed
   - Any breaking changes

### Documentation

- Help improve documentation
- Create tutorials or videos
- Translate to other languages
